# Portfolio - Abraão Moreira

Site pessoal recriado em **Next.js** (App Router).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Testes

```bash
npm test
```

Os testes cobrem as principais funcionalidades da área interna (`/sistema`), incluindo login e gestão de projetos.

O site antigo em HTML estático permanece na pasta `refactor/` por enquanto.
